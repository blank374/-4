# 任务一：五种单目标最优路径

## 数学模型

对城市网络建模为有向图 `G=(V,E)`。每条有向边 `e=(u,v)` 有非负向量
`w(e)=(d(e),t(e),h(e),a(e),q(e))`，分别对应 distance、travel_time、elevation、avg_degree、hop_count。
对路径 `P=(v0,...,vk)` 定义

`C_i(P)=Σ_{j=0}^{k-1} w_i(v_j,v_{j+1}), i=1,...,5`。

对每一个 query `(s,r)` 和目标 `i`，求

`min C_i(P)`，约束为 `v0=s`、`vk=r`、每一对相邻节点必须属于 `E`，且 `v0,...,vk` 两两不同。

权重非负时，任意含环路径都可以删去环而不增加目标值，因此最短路算法得到的最优解可取为无重复节点的合法路径。

## 算法

程序 `task1_solver.py` 只读取一次每个城市的统一五权重边文件，将其组织为邻接表
`adj[u]=[(v, costs)]`。对每个查询分别以五个目标权重作为边长运行 Dijkstra：优先队列为
`heapq`，每个节点只在第一次弹出最小暂定距离后定型，并在目标节点定型时提前结束。
前驱表同时保存前驱节点和实际边对象，回溯得到完整节点序列和边序列；这也正确处理了潜在的平行边。

回溯后进行四项自检：路径首尾、边数与节点数、节点不重复、每个相邻节点对确实存在有向边。
最后使用回溯得到的完整边序列重新累加五个成本，输出的 `c1-c5` 不使用 Dijkstra 内部的距离值。

## 复杂度

设 `n=|V|`、`m=|E|`。邻接表建图时间 `O(n+m)`、空间 `O(n+m)`。
一次二叉堆 Dijkstra 的时间复杂度为 `O((n+m)log n)`，空间为 `O(n+m)`；提前到达目标通常更快，
但不改变最坏情况保证。每个查询运行五次，100 组查询的最坏时间为
`O(500(n+m)log n)`，三个城市分别独立处理。图数据在五个目标和所有查询间复用，避免重复加载；
若多个查询共享源点，可进一步缓存单源结果，但本实现保留目标提前终止以降低单次查询开销和内存峰值。

## 三城市冲突指标分析方法

将每个城市所有边的五维向量分别计算 Pearson/Spearman 相关系数矩阵，负相关或绝对相关性低表示
边层面的目标冲突/独立性。再对每个 query 的五条输出路径，计算任一目标路径在其他目标上的归一化
代价 `C_j(P_i)/C_j(P_j^*)`（相对代价或 regret），以及路径节点集合/边集合的 Jaccard 相似度。
其中大于 1 的相对代价表示为优化目标 i 所付出的 j 目标代价；不同目标路径差异越大、相对代价越高，
说明冲突越强。城市层面报告100组查询的均值、中位数、标准差、最大值和95%分位数，并比较三城市的
相关矩阵、regret 矩阵、路径重合率和五目标路径完全相同的比例。对于零均值或零方差列，相关系数标记
为不可定义，不用人为填充；报告中同时保留原始累计值，避免归一化掩盖量纲差异。

## 输出

默认将 NY、BAY、COL 三个城市合并生成一个 `result1_研XXX.csv`。
每个文件包含严格列：`dataset,query_id,source,target,objective,c1,c2,c3,c4,c5,path`，
每个城市 100×5=500 行数据，路径格式为 `v0->v1->...->vk`。
